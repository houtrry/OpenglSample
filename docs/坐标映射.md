## 坐标映射
[坐标系统](https://learnopengl-cn.github.io/01%20Getting%20started/08%20Coordinate%20Systems/)  
![learn opengl](https://learnopengl-cn.github.io/img/01/08/coordinate_systems.png)
通常，在OpenGL里，我们的坐标计算牵扯到以下几个坐标矩阵：

- projectionMatrix 投影矩阵
- viewMatrix 视图矩阵(观察矩阵)
- modelMatrix 模型矩阵
- mvpMatrix 模型-视图-投影矩阵

### 矩阵变换流程
```
局部空间 → 世界空间 → 相机空间 → 裁剪空间 → 屏幕空间
   ↓         ↓         ↓         ↓         ↓
modelMatrix viewMatrix projectionMatrix
   ↓         ↓         ↓
   └─────────┴─────────┘
        mvpMatrix
```

首先明确一点，
```
mvpMatrix = projectionMatrix * viewMatrix * modelMatrix  
```
其中，projectionMatrix/viewMatrix/modelMatrix的顺序不能变。

下面我们一一做解释
### 1. projectionMatrix 投影矩阵
将物体从相机空间变换到裁剪空间

#### 1.1 透视投影 vs 正交投影
```
透视投影 (Perspective Projection)
    /\
   /  \    近大远小效果
  /    \   模拟人眼视觉
 /      \
/        \

正交投影 (Orthographic Projection)
    ┌──┐
    │  │    无透视效果
    │  │   平行线保持平行
    │  │
    └──┘
```

有两种投影矩阵：
- **透视投影**，模拟近大远小，3D绘图通常使用这个
```java
Matrix.perspectiveM(
    projectionMatrix, 0,
    (float) Math.toRadians(45.0f), // FOV (弧度)
    screenWidth / screenHeight, // 宽高比
    0.1f, 100.0f // 近/远平面
);
```
- **正交投影**，无透视效果，也就是远/近看到的效果一样，2D绘图通常使用这个
```java
Matrix.orthoM(
    projectionMatrix, 0,
    -1.0f, 1.0f, // left/right
    -1.0f, 1.0f, // bottom/top
    0.1f, 100.0f // near/far
);
```
注意，这里的near/far都只能是正数

**参数详解：**
- **FOV (Field of View)**: 视野角度，通常45-60度，角度越大视野越宽但可能产生鱼眼效果
- **宽高比**: 屏幕宽度除以高度，影响物体的拉伸程度
- **近/远平面**: 定义可见范围，物体必须在近平面和远平面之间才能被渲染

### 2. viewMatrix 视图矩阵(观察矩阵)
将物体从世界空间变换到相机空间（观察空间），世界坐标 → 相机坐标,  
实际是定义相机的位置和方向（即"观察者"的视角）。
```java
Matrix.setLookAtM(
    viewMatrix, 0,
    0f, 0f, 3f, // 相机位置
    0f, 0f, 0f, // 观察目标
    0f, 1f, 0f  // 上向量
);
```

注意，  
已知投影矩阵里，near/far的值，视图矩阵里相机位置(eye)的位置(eye_x, eye_y, eye_z),
那z的可见范围是[eye_z - far, eye_z - near]，z超出这个范围的物体不会被显示。

**参数详解：**
- **相机位置 (eyeX, eyeY, eyeZ)**: 相机在世界空间中的位置
- **观察目标 (centerX, centerY, centerZ)**: 相机看向的点，决定相机的朝向
- **上向量 (upX, upY, upZ)**: 定义相机的"上"方向，通常是(0,1,0)

### 3. modelMatrix 模型矩阵
将物体从局部空间变换到世界空间，定义物体的位置、旋转、缩放等变换。

#### 3.1 基本变换类型
```
平移 (Translation)
    ┌─┐
    │ │     ┌─┐
    └─┘  →  │ │
            └─┘
    原点    移动后

旋转 (Rotation)
    ┌─┐
    │ │  →  ┌─┐
    └─┘     │ │
            └─┘
    原始    旋转后

缩放 (Scale)
    ┌─┐
    │ │  →  ┌─────┐
    └─┘     │     │
            └─────┘
    原始    放大后
```

**基本变换方法：**

#### 3.2 平移变换 (Translation)
```java
Matrix.translateM(modelMatrix, 0, 2.0f, 0.0f, -3.0f);
// 参数：矩阵, 偏移量, x偏移, y偏移, z偏移
// 效果：将物体沿x轴移动2单位，沿z轴移动-3单位

平移效果示意图：
    Y
    ↑
    |    物体
    |   ↗
    | ↗
    +--------→ X
    原点

    平移后：
    Y
    ↑
    |     
    |     
    |     
    +--------→ X
    原点    物体
```

#### 3.3 旋转变换 (Rotation)
```java
// 绕X轴旋转45度
Matrix.rotateM(modelMatrix, 0, 45.0f, 1.0f, 0.0f, 0.0f);

// 绕Y轴旋转90度  
Matrix.rotateM(modelMatrix, 0, 90.0f, 0.0f, 1.0f, 0.0f);

// 绕Z轴旋转180度
Matrix.rotateM(modelMatrix, 0, 180.0f, 0.0f, 0.0f, 1.0f);

旋转轴示意图：
    Y (上轴)
    ↑
    |     Z (前轴)
    |   ↗
    | ↗
    +--------→ X (右轴)

绕X轴旋转：
    Y
    ↑
    |    物体绕X轴旋转
    |   ↗
    | ↗
    +--------→ X

绕Y轴旋转：
    Y
    ↑
    |     
    |     物体绕Y轴旋转
    |   ↗
    +--------→ X

绕Z轴旋转：
    Y
    ↑
    |     
    |     
    |     物体绕Z轴旋转
    +--------→ X
```
**参数详解：**
- **角度**: 旋转角度（度），正值逆时针旋转
- **轴向量**: (x, y, z) 表示旋转轴的方向向量

#### 3.4 缩放变换 (Scale)
```java
Matrix.scaleM(modelMatrix, 0, 2.0f, 1.5f, 0.5f);
// 参数：矩阵, 偏移量, x缩放, y缩放, z缩放
// 效果：x方向放大2倍，y方向放大1.5倍，z方向缩小到0.5倍

缩放效果示意图：
原始物体：
    ┌─┐
    │ │
    └─┘

X方向放大2倍：
    ┌─────┐
    │     │
    └─────┘

Y方向放大1.5倍：
    ┌─┐
    │ │
    │ │
    │ │
    └─┘

Z方向缩小0.5倍：
    ┌─┐
    └─┘
```

#### 3.5 组合变换
```java
// 注意：变换的顺序很重要！通常是 缩放 -> 旋转 -> 平移
Matrix.setIdentityM(modelMatrix, 0);  // 重置为单位矩阵
Matrix.scaleM(modelMatrix, 0, 2.0f, 2.0f, 2.0f);  // 先缩放
Matrix.rotateM(modelMatrix, 0, 45.0f, 0.0f, 1.0f, 0.0f);  // 再旋转
Matrix.translateM(modelMatrix, 0, 1.0f, 0.0f, 0.0f);  // 最后平移

变换顺序的重要性：
错误顺序：平移 -> 旋转 -> 缩放
    ┌─┐
    │ │  →  移动  →  旋转  →  缩放
    └─┘

正确顺序：缩放 -> 旋转 -> 平移
    ┌─┐
    │ │  →  缩放  →  旋转  →  移动
    └─┘
```

### 4. mvpMatrix 模型-视图-投影矩阵
这是最终的变换矩阵，将顶点从局部空间直接变换到裁剪空间。

#### 4.1 矩阵乘法流程
```
modelMatrix × viewMatrix × projectionMatrix = mvpMatrix

┌─┐   ┌─┐   ┌─┐     ┌─┐
│M│ × │V│ × │P│  =  │MVP│
└─┘   └─┘   └─┘     └─┘

计算步骤：
1. temp = M × V
2. MVP = P × temp
```

```java
// 计算MVP矩阵
Matrix.multiplyMM(mvpMatrix, 0, viewMatrix, 0, modelMatrix, 0);
Matrix.multiplyMM(mvpMatrix, 0, projectionMatrix, 0, mvpMatrix, 0);
```

**参数详解：**
- **result**: 存储结果的矩阵
- **resultOffset**: 结果矩阵的偏移量
- **lhs**: 左操作数矩阵
- **lhsOffset**: 左操作数矩阵的偏移量
- **rhs**: 右操作数矩阵
- **rhsOffset**: 右操作数矩阵的偏移量

### 5. 完整代码示例

```java
import android.opengl.Matrix;
import android.opengl.GLES20;

public class CoordinateSystemExample {
    private float[] projectionMatrix = new float[16];
    private float[] viewMatrix = new float[16];
    private float[] modelMatrix = new float[16];
    private float[] mvpMatrix = new float[16];
    private int mvpMatrixHandle; // 着色器中的uniform句柄
    
    public void setupMatrices(int screenWidth, int screenHeight) {
        // 1. 设置投影矩阵 - 透视投影
        float aspectRatio = (float) screenWidth / screenHeight;
        Matrix.perspectiveM(projectionMatrix, 0, 
            (float) Math.toRadians(45.0f), aspectRatio, 0.1f, 100.0f);
        
        // 2. 设置视图矩阵 - 相机位置和朝向
        Matrix.setLookAtM(viewMatrix, 0,
            0.0f, 0.0f, 3.0f,  // 相机位置：在z轴正方向3单位处
            0.0f, 0.0f, 0.0f,  // 观察目标：原点
            0.0f, 1.0f, 0.0f   // 上向量：y轴正方向
        );
        
        // 3. 设置模型矩阵 - 物体变换
        Matrix.setIdentityM(modelMatrix, 0);  // 重置为单位矩阵
        Matrix.translateM(modelMatrix, 0, 0.0f, 0.0f, -5.0f);  // 移动到z轴负方向
        Matrix.rotateM(modelMatrix, 0, 45.0f, 0.0f, 1.0f, 0.0f);  // 绕Y轴旋转45度
        
        // 4. 计算MVP矩阵
        Matrix.multiplyMM(mvpMatrix, 0, viewMatrix, 0, modelMatrix, 0);
        Matrix.multiplyMM(mvpMatrix, 0, projectionMatrix, 0, mvpMatrix, 0);
    }
    
    public void render() {
        // 将MVP矩阵传递给着色器
        GLES20.glUniformMatrix4fv(mvpMatrixHandle, 1, false, mvpMatrix, 0);
        // 绘制物体...
    }
}
```

// 相机跟随鼠标移动
public void updateFirstPersonCamera(float mouseX, float mouseY) {
    // 计算相机位置（假设在原点）
    float cameraX = 0.0f;
    float cameraY = 0.0f;
    float cameraZ = 0.0f;
    
    // 计算观察目标（基于鼠标位置）
    float targetX = (float) Math.sin(mouseX) * 5.0f;
    float targetZ = (float) Math.cos(mouseX) * 5.0f;
    float targetY = mouseY * 2.0f;
    
    Matrix.setLookAtM(viewMatrix, 0,
        cameraX, cameraY, cameraZ,  // 相机位置
        targetX, targetY, targetZ,  // 观察目标
        0.0f, 1.0f, 0.0f           // 上向量
    );
}

public void animateObject(float deltaTime) {
    static float rotationAngle = 0.0f;
    rotationAngle += deltaTime * 50.0f;  // 每秒旋转50度
    
    Matrix.setIdentityM(modelMatrix, 0);
    Matrix.translateM(modelMatrix, 0, 2.0f, 0.0f, 0.0f);  // 移动到右侧
    Matrix.rotateM(modelMatrix, 0, rotationAngle, 0.0f, 1.0f, 0.0f);  // 绕Y轴旋转
}

#### 6.3 多物体渲染
```
多物体排列示意图：
物体1  物体2  物体3  物体4
┌─┐   ┌─┐   ┌─┐   ┌─┐
│ │   │ │   │ │   │ │

```

```java
// 渲染多个物体，每个物体有不同的模型矩阵
public void renderMultipleObjects() {
    for (int i = 0; i < objectCount; i++) {
        // 为每个物体创建独立的模型矩阵
        Matrix.setIdentityM(modelMatrix, 0);
        Matrix.translateM(modelMatrix, 0, i * 2.0f, 0.0f, 0.0f);  // 水平排列
        Matrix.rotateM(modelMatrix, 0, i * 30.0f, 0.0f, 1.0f, 0.0f);  // 不同角度
        
        // 计算当前物体的MVP矩阵
        Matrix.multiplyMM(mvpMatrix, 0, viewMatrix, 0, modelMatrix, 0);
        Matrix.multiplyMM(mvpMatrix, 0, projectionMatrix, 0, mvpMatrix, 0);
        
        // 渲染物体
        GLES20.glUniformMatrix4fv(mvpMatrixHandle, 1, false, mvpMatrix, 0);
        drawObject();
    }
}
```

### 7. 常见问题和调试技巧

#### 7.1 物体不可见
```
可见性检查示意图：
    Y
    ↑
    |    远平面 (100)
    |   ↗
    | ↗
    +--------→ X
    近平面 (0.1)

物体必须在近平面和远平面之间才能被渲染
```

- 检查物体是否在近/远平面范围内
- 确认相机位置和观察目标设置正确
- 验证模型矩阵的变换是否合理

#### 7.2 物体变形
```
变形问题示意图：
正常比例：    宽高比错误：
┌─────┐      ┌─────────────┐
│     │      │             │
│     │      │             │
└─────┘      └─────────────┘
```

- 检查宽高比设置是否正确
- 确认FOV角度是否合适
- 验证缩放参数是否合理

#### 7.3 性能优化
```
优化策略示意图：
静态物体：    动态物体：
┌─┐          ┌─┐
│ │ 预计算   │ │ 每帧计算
└─┘ MVP矩阵  └─┘ MVP矩阵
```

- 对于静态物体，预计算MVP矩阵
- 使用矩阵池避免频繁创建新矩阵
- 批量渲染相同材质的物体

### 矩阵参数间的配合与影响关系

#### 投影矩阵参数对后续矩阵的影响

投影矩阵的参数设置会直接影响viewMatrix和modelMatrix中参数的选择。下面以屏幕大小500×350为例，详细说明不同投影参数的影响：

##### 1. 正交投影参数对比

**情况A：标准化坐标 (-1,1)**
```java
// 投影矩阵：使用标准化坐标
Matrix.orthoM(projectionMatrix, 0,
    -1.0f, 1.0f,    // left/right
    -1.0f, 1.0f,    // bottom/top  
    0.1f, 100.0f    // near/far
);
```

**情况B：像素坐标 (-250,250)**
```java
// 投影矩阵：使用像素坐标
Matrix.orthoM(projectionMatrix, 0,
    -250.0f, 250.0f,  // left/right
    -175.0f, 175.0f,  // bottom/top
    0.1f, 100.0f      // near/far
);
```

**情况C：正方形坐标 (-250,250)**
```java
// 投影矩阵：使用正方形坐标
Matrix.orthoM(projectionMatrix, 0,
    -250.0f, 250.0f,  // left/right
    -250.0f, 250.0f,  // bottom/top
    0.1f, 100.0f      // near/far
);
```

    private float[] viewMatrix = new float[16];
    private float[] modelMatrix = new float[16];
    private float[] mvpMatrix = new float[16];

        GLES20.glViewport(0, 0, viewWidth, viewHeight);

    }

**场景2：不同变换的多个纹理**
```java
// 创建完整的模型矩阵（包含所有变换）
Matrix.setIdentityM(modelMatrix, 0);
// 应用所有变换：缩放 -> 旋转 -> 平移
Matrix.scaleM(modelMatrix, 0, 2.0f, 1.5f, 1.0f);  // 缩放
Matrix.rotateM(modelMatrix, 0, 45.0f, 0.0f, 0.0f, 1.0f);  // 绕Z轴旋转45度
Matrix.translateM(modelMatrix, 0, 100.0f, 200.0f, 0.0f);  // 平移

// 渲染不同纹理时，根据需求提取特定分量
// 纹理1：平移/旋转/缩放都有
mvpMatrix1 = projectionMatrix * viewMatrix * modelMatrix * textureSizeMatrix1

// 纹理2：只有平移/旋转
mvpMatrix2 = projectionMatrix * viewMatrix * modelMatrix.getTransform(true, true, false) * textureSizeMatrix2

// 纹理3：只有平移
mvpMatrix3 = projectionMatrix * viewMatrix * modelMatrix.getTransform(true, false, false) * textureSizeMatrix3

/**
 * 获取矩阵的分量
 * @param hasTranslate 有平移分量
 * @param hasRotate 有旋转分量
 * @param hasScale 有缩放分量
 */
fun FloatArray.getTransform(hasTranslate: Boolean, hasRotate: Boolean, hasScale: Boolean): FloatArray {
    val resultMatrix = FloatArray(16)
    Matrix.setIdentityM(resultMatrix, 0)
    
    if (hasScale) {
        // 提取缩放分量（从矩阵对角线元素）
        val scaleX = sqrt(this[0] * this[0] + this[1] * this[1] + this[2] * this[2])
        val scaleY = sqrt(this[4] * this[4] + this[5] * this[5] + this[6] * this[6])
        val scaleZ = sqrt(this[8] * this[8] + this[9] * this[9] + this[10] * this[10])
        Matrix.scaleM(resultMatrix, 0, scaleX, scaleY, scaleZ)
    }
    
    if (hasRotate) {
        // 提取旋转分量（简化处理，假设绕Z轴旋转）
        val angle = atan2(this[1], this[0])
        Matrix.rotateM(resultMatrix, 0, Math.toDegrees(angle.toDouble()).toFloat(), 0.0f, 0.0f, 1.0f)
    }
    
    if (hasTranslate) {
        // 提取平移分量（矩阵的最后一列）
        Matrix.translateM(resultMatrix, 0, this[12], this[13], this[14])
    }
    
    return resultMatrix
}
```

##### 9.9.9 最佳实践总结

**核心原则：**

6. 计算并应用MVP矩阵
7. 批量渲染优化性能
