## 1 目标
这是为机器人做的建图软件，建图时，算法使用机器人正前方的lidar（270°，或者360°）扫描前方障碍物，生成实时地图，上层业务进行预览显示，现在要做的就是这个高性能的实时预览的显示这个部分。
当前项目需求里，这块功能主要包括如下几项：
- 实时地图的渲染（核心需求）
- 机器人icon的渲染（用于表示当前机器人在地图里的哪个位置）（核心需求）
- 标记点的渲染（允许用户添加部分标记点，标记点由气泡+icon+文字组成）（核心需求）
- 绘制折线
- 绘制离散的点
- 绘制多边形

### 1.1 地图绘制
1. 纹理可能会很大，比如纹理的宽高是20000*20000，因此，需要考虑使用Tile方案去切分，避免单个纹理很大的情况（如果有更好的方案，可以提出讨论）
2. 业务上，纹理可能会有如下情况
   1. 新建地图：一开始，纹理大小是0*0，或者一个很小的值，然后，随着推图的进行逐渐变大
   2. 扩展地图：一开始，纹理大小是一个值（可能是200*200，也可能是20000*20000），然后，随着推图的进行逐渐变大
3. 需要考虑支持两种渲染方式
   1. 每一帧都渲染整个纹理（但是算法生成完整帧纹理的耗时比较长）（当前算法未更新的情况下，暂时采用该方案）
   2. 每一帧不再更新整个纹理，而是只更新某一个固定大小的正方形区域（后续算法更新后，采用该方案）（因为lidar扫描的范围有限，也就意味着，每次会发生更新的区域，只是机器人正前方的部分区域，但是要注意，机器人会旋转）
      1. 正方形的大小可调，当然，基于这个场景，也并不一定非要是正方形，也可以是别的形状的区域更新
      2. 正方形所在的位置并不固定（因为机器人在移动）
      3. 地图可能会逐渐变大，Tile可能会有需要增加的情况
4. 算法返回的预览地图是灰度图（由灰/黑/白组成），不符合UI设计的效果，UI期望是蓝色/淡蓝色/灰色组成的图，因此，需要做颜色的映射
5. 需要支持用户的手势操作，单指拖拽平移，双指缩放/旋转
6. 地图变大的过程中，地图左下角在机器人世界坐标系里的定位位置/resolution（一个像素在机器人世界坐标系里的大小）也是变化的，这个会影响到机器人icon/标记点位置的计算

### 1.2 机器人icon的渲染
1. 机器人icon应在地图层级的上层，不被地图遮挡
2. 地图发生平移/旋转的过程中，机器人icon跟随平移/旋转，以保证机器人icon在地图上的相对位置/朝向都正确，但是不跟随缩放，机器人icon大小应该固定

### 1.3 标记点的渲染
1. 标记点的个数可能会有2000+
   1. 新建地图时，初始没有标记点，用户通过交互一个一个添加，没有个数上限
   2. 扩展地图时，初始已经存在地图已经有的标记点，可能是0~2000+个，之后，用户通过交互一个一个添加，没有个数上限
   3. 不管是新建还是扩展，用户都可以通过交互，一个一个的删除标记点
2. 地图发生平移的过程中，标记点都应该跟随平移，但是不跟随旋转/缩放。手势操作过程中，标记点相对于地图的位置不变。
3. 支持配置样式，比如文字颜色/大小/行间距/padding/icon和文字之间的间距，配置icon，配置气泡的圆角大小/箭头的位置/大小/stoke的颜色/宽度/填充的颜色等
4. 支持动态修改某一个或者多个标记点的气泡颜色，icon，文字颜色/大小等参数
5. 气泡+icon+文字是标配，但是只有文字是必须有的，气泡/icon可以通过参数进行配置
6. icon和文字的位置，可以是上下，也可以是左右，可以通过参数进行配置
7. 文字考虑支持30+种多语言，包括中文/英语/阿拉伯语/法语/俄语/日语/韩语/泰语等
8. 需要考虑文字RTL和LTR
9. 文字可以用过配置maxWidth来限制，超出maxWidth进行换行，当然，也允许用户不设置maxWidth，默认值就是-1，这个时候不需要进行换行操作，单行显示全部的文字

### 1.4 绘制折线
1. 折线是由一系列离散的点连接组成的
2. 折线的点支持动态更新
3. 折线的宽度/样式可以通过参数配置，也可以支持渐变的线条颜色
4. 手势操作过程中，折线跟随平移/旋转；可以配置折线的线条宽度是否跟随缩放，默认不跟随。
5. 支持用户点击选中操作，选中后，可以平移这个折线（平移过程中，地图是不响应触摸事件的），默认不支持响应点击选中和拖拽。
6. 允许有多个折线，折线与折线之间互相独立。
7. 每个折线可以有一个字符串组成的名字，显示用，也可以没有。

### 1.5 绘制离散的点
1. 目前只考虑支持圆形离散的点，也即是，在每个离散的点的位置绘制一个圆
2. 圆的大小/颜色可以通过参数配置，默认红色，半径12个像素
3. 手势操作过程中，圆跟随地图平移/旋转；可以配置圆的半径是否跟随缩放，默认不跟随。
4. 离散的点个数可能有2000+，并且动态变化
5. 不支持选中

### 1.6 绘制多边形
1. 只考虑支持简单多边形
2. 多边形的样式支持配置，包括各个顶点的样式（可以是一个实心圆，也可以是多个不同颜色的同心圆组成的），border的颜色/宽度/实线or虚线/虚线的间隔，多边形的solid颜色等等，支持配置渐变色
3. 手势操作过程中，多边形跟随地图平移/旋转/缩放；可以配置多边形的border的宽度是否跟随缩放，默认不跟随。
4. 多边形个数可能有2000+，并且动态变化
5. 默认不支持选中，如果配置了支持选中，用户点击这个多边形选中后，多边形的单个顶点可以拖拽，用于修改多边形的形状；多边形的中心区可以拖拽整体平移
6. 每个多边形可以有一个字符串组成的名字，显示用，也可以没有。
